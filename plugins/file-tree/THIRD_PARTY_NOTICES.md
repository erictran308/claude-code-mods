## claude-code-filetree

file-tree is inspired by claude-code-filetree, and a few small things derive from it: the shimmer's sweep, the git flags that avoid taking locks, the way a git path maps onto the tree, the invisible click area laid over each row, and the idea of closing folders opened for Claude.

Source: https://github.com/data-goblin/claude-code-filetree

## Material Icon Theme

`assets/icons` holds the icons of Material Icon Theme 5.40.0, turned from SVG into PNG, and the theme's map from file and folder names to icons.

Source: https://github.com/material-extensions/vscode-material-icon-theme

## ratatui

`hooks/art.ts` ports rendering techniques from ratatui to TypeScript: Gauge, HalfBlockGrid and the braille marker.
